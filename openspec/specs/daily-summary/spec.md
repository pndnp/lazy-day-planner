# daily-summary Specification

## Purpose
Обеспечивает ежедневную рассылку напоминаний о событиях пользователям.

## Requirements

### Requirement: Scheduled Daily Summary
Система должна отправлять ежедневную рассылку в заданное время.

#### Scenario: Send daily summary at scheduled time
- **Given** система запущена
- **WHEN** наступает время SUMMARY_HOUR:SUMMARY_MINUTE (08:08)
- **THEN** система собирает события всех пользователей на сегодня
- **AND** отправляет каждому пользователю сообщение с планом на день

#### Scenario: Summary format
- **Given** у пользователя есть события на сегодня
- **WHEN** система формирует сообщение
- **THEN** сообщение содержит заголовок "План на сегодня:"
- **AND** каждый день выводится в формате "День Дата — Название"
- **AND** если указана локация — добавляется " • Локация"

### Requirement: Skip Empty Summaries
Система должна позволять пользователям отключать рассылку при отсутствии событий.

#### Scenario: Skip empty summary for user
- **Given** у пользователя включена настройка skip_empty
- **AND** у пользователя нет событий на сегодня
- **WHEN** система формирует рассылку
- **THEN** система не отправляет сообщение этому пользователю

#### Scenario: Send empty summary for user
- **Given** у пользователя выключена настройка skip_empty
- **AND** у пользователя нет событий на сегодня
- **WHEN** система формирует рассылку
- **THEN** система отправляет сообщение "На сегодня планов нет. Какой прекрасный день!"

### Requirement: Expired Events Cleanup
Система должна автоматически удалять прошедшие события при отправке рассылки.

#### Scenario: Delete expired events
- **Given** есть события с датой в прошлом
- **WHEN** запускается daily summary
- **THEN** система удаляет все события, у которых date_time < now
- **AND** система коммитит изменения в базу данных
