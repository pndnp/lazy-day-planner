# event-creation Specification

## Purpose
Позволяет пользователям создавать события через интерактивный воркфлоу с inline календарём.

## Requirements

### Requirement: Event Creation Wizard
Система должна предоставлять FSM воркфлоу для создания событий через команду /add.

#### Scenario: Start event creation
- **Given** пользователь отправляет команду /add
- **WHEN** система получает команду
- **THEN** пользователь видит запрос на ввод названия события с кнопкой "Отменить"

#### Scenario: Collect event title
- **Given** пользователь находится в состоянии ожидания названия
- **WHEN** пользователь отправляет не пустое название
- **THEN** система сохраняет название и переходит к выбору даты с inline календарём
- **AND** пользователь видит запрос на выбор даты

#### Scenario: Cancel event creation
- **Given** пользователь находится в процессе создания события
- **WHEN** пользователь нажимает кнопку "Отменить"
- **THEN** состояние сбрасывается
- **AND** пользователь получает сообщение об отмене

### Requirement: Date Selection via Inline Calendar
Система должна предоставлять интерактивный календарь для выбора даты события.

#### Scenario: Display calendar
- **Given** пользователь выбрал название события
- **WHEN** система переходит к выбору даты
- **THEN** пользователь получает inline календарь с кнопками навигации по месяцам
- **AND** пользователь видит быстрые кнопки "Сегодня" и "Завтра"

#### Scenario: Select date from calendar
- **Given** пользователь видит inline календарь
- **WHEN** пользователь нажимает на ячейку с датой
- **THEN** система сохраняет дату и переходит к вводу времени
- **AND** пользователь видит запрос на ввод времени в формате hh:mm

#### Scenario: Navigate calendar months
- **Given** пользователь видит inline календарь
- **WHEN** пользователь нажимает кнопки "←" или "→"
- **THEN** система отображает предыдущий или следующий месяц

### Requirement: Time and Location Collection
Система должна собирать время и optional локацию события.

#### Scenario: Collect event time
- **Given** пользователь выбрал дату события
- **WHEN** пользователь отправляет время в формате hh:mm
- **THEN** система сохраняет время и переходит к вводу локации
- **AND** пользователь видит запрос на ввод места с кнопками "Пропустить" и "Отменить"

#### Scenario: Skip location
- **Given** пользователь выбрал дату и время события
- **WHEN** пользователь нажимает кнопку "Пропустить"
- **THEN** система сохраняет событие с location=null
- **AND** пользователь получает подтверждение о создании события

#### Scenario: Collect event location
- **Given** пользователь выбрал дату и время события
- **WHEN** пользователь отправляет текст локации
- **THEN** система сохраняет событие с указанной локацией
- **AND** пользователь получает подтверждение о создании события

### Requirement: Event Persistence
Система должна сохранять событие в базу данных.

#### Scenario: Save event to database
- **Given** пользователь заполнил все обязательные поля события
- **WHEN** система получает подтверждение
- **THEN** система создаёт объект Event с title, date_time, location и user_id
- **AND** система сохраняет событие в базу данных через SQLAlchemy
