# Event Viewing Specification

## Purpose
Позволяет пользователям просматривать события по различным периодам (сегодня, завтра, неделя).

## ADDED Requirements

### Requirement: View Events by Day
Система должна отображать события для конкретного дня.

#### Scenario: View today's events
- **Given** пользователь отправляет команду /today
- **WHEN** система обрабатывает команду
- **THEN** система фильтрует события пользователя на текущий день
- **AND** если события есть — выводит список с заголовком "План на сегодня:"
- **AND** если событий нет — выводит сообщение "На сегодня планов нет. Какой прекрасный день!"

#### Scenario: View tomorrow's events
- **Given** пользователь отправляет команду /tomorrow
- **WHEN** система обрабатывает команду
- **THEN** система фильтрует события пользователя на завтра
- **AND** если события есть — выводит список с заголовком "План на завтра:"
- **AND** если событий нет — выводит сообщение "На завтра планов нет. Какой прекрасный день!"

### Requirement: View Events by Week
Система должна отображать события для недельных периодов.

#### Scenario: View current week events
- **Given** пользователь отправляет команду /week
- **WHEN** система обрабатывает команду
- **THEN** система фильтрует события пользователя на текущую неделю (понедельник-воскресенье)
- **AND** если события есть — выводит список с заголовком "План на эту неделю:"
- **AND** если событий нет — выводит сообщение "Нет планов на эту неделю"

#### Scenario: View next week events
- **Given** пользователь отправляет команду /next_week
- **WHEN** система обрабатывает команду
- **THEN** система фильтрует события пользователя на следующую неделю
- **AND** если события есть — выводит список с заголовком "План на следующую неделю:"
- **AND** если событий нет — выводит сообщение "Нет планов на следующую неделю"

### Requirement: View All Events
Система должна отображать все события пользователя.

#### Scenario: List all events
- **Given** пользователь отправляет команду /all
- **WHEN** система обрабатывает команду
- **THEN** система выводит все события пользователя, отсортированные по дате
- **AND** каждое событие выводится с форматом "День Дата — Название (ID)"
- **AND** если событий нет — выводит сообщение "Нет планов"

### Requirement: Delete Events
Система должна позволять удалять события по ID.

#### Scenario: Delete event by ID
- **Given** пользователь отправляет команду /del с ID события
- **WHEN** система обрабатывает команду
- **THEN** система находит событие пользователя с указанным ID
- **AND** если событие найдено — удаляет его и выводит "Событие 'Название' удалено"
- **AND** если событие не найдено — выводит "Событие с ID X не найдено"

#### Scenario: Invalid delete command
- **Given** пользователь отправляет /del без ID или с некорректным ID
- **WHEN** система обрабатывает команду
- **THEN** система выводит подсказку "Используйте: /del <ID события>"
