# User Management Specification

## Purpose
Управляет пользователями бота, их регистрацией и настройками.

## ADDED Requirements

### Requirement: User Registration
Система должна автоматически регистрировать пользователей при первом взаимодействии.

#### Scenario: Register new user on /start
- **Given** пользователь отправляет команду /start
- **WHEN** система обрабатывает команду
- **THEN** система создаёт запись пользователя с telegram_id
- **AND** пользователь получает приветственное сообщение с описанием возможностей бота

#### Scenario: Welcome message content
- **Given** пользователь регистрируется
- **WHEN** система отправляет приветственное сообщение
- **THEN** сообщение содержит текст "Привет! Я бот-напоминалка."
- **AND** описывает команды /add, /today, /tomorrow, /week, /skipempty, /help
- **AND** упоминает время ежедневной рассылки (08:08)

### Requirement: User Settings Management
Система должна хранить и управлять настройками пользователей.

#### Scenario: Store settings as JSON
- **Given** у пользователя есть настройки
- **THEN** настройки хранятся в поле settings_json как JSON-строка
- **AND** система предоставляет методы get_setting, set_setting, toggle_setting

#### Scenario: Toggle skip_empty setting
- **Given** пользователь отправляет команду /skipempty
- **WHEN** система обрабатывает команду
- **THEN** система переключает настройку skip_empty
- **AND** если включено — выводит сообщение "Пропуск пустых рассылок: включено"
- **AND** если выключено — выводит сообщение "Пропуск пустых рассылок: отключено"

### Requirement: User-Event Relationship
Система должна связывать события с пользователями.

#### Scenario: Create event for user
- **Given** пользователь создаёт событие
- **WHEN** система сохраняет событие
- **THEN** система связывает событие с пользователем через user_id
- **AND** пользователь автоматически создаётся при создании события, если не существует

#### Scenario: User owns events
- **Given** у пользователя есть события
- **THEN** каждый событие принадлежит только одному пользователю
- **AND** пользователь может удалять только свои события
